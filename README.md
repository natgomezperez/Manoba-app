# Manoba — Nat 5 Maths Practice

A free, offline-capable maths practice app for Scottish National 5 students.
Runs entirely in the browser — no server, no login, no cost.

- Unlimited randomly generated questions across 14 topics
- Hints and full worked solutions
- Adapts to weaker topics
- Progress tracked on the device (saved in the browser)

## Put it online with GitHub Pages (about 5 minutes)

1. Create a free account at https://github.com
2. Click **+** (top right) → **New repository**. Name it `manoba`, set it to **Public**, click **Create repository**.
3. Click **uploading an existing file**, drag in ALL the files from this folder
   (`index.html`, `manifest.json`, `sw.js`, the three `icon-*.png` files, and this README), then click **Commit changes**.
4. Go to **Settings → Pages**. Under *Build and deployment*, set **Source** to *Deploy from a branch*,
   choose branch **main** and folder **/ (root)**, then **Save**.
5. Wait a minute or two. Your link will be:
   `https://YOUR-USERNAME.github.io/manoba/`

## Install on a phone

- **iPhone (Safari):** open the link → Share button → **Add to Home Screen**
- **Android (Chrome):** open the link → menu (⋮) → **Install app** / **Add to Home screen**

It then opens full screen like a normal app and works offline after the first visit.

## Good to know

- Progress is stored **on that phone, in that browser**. Using a different phone or browser starts fresh,
  and clearing browser data erases it.
- To start again, use **Progress → Reset all progress**.
- Answers are checked automatically. The input box shows the expected format
  (e.g. `3/4`, `4sqrt3`, `y = 2x + 3`, `x = 2, y = -1`).

## Updating

Edit a file on GitHub (pencil icon) and commit. The site updates within a minute.
If a phone still shows the old version, close and reopen the app once.
